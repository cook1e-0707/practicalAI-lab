# Practical AI Summer Camp Labs

Student lab materials for the UMass Boston AI summer camp. The notebooks are
designed to run in Google Colab, so no local Python installation is required.

## Week 1, Day 1: Python, Data, and a First Machine-Learning Model

[Open the Week 1, Day 1 student lab in Google Colab](https://colab.research.google.com/github/cook1e-0707/practicalAI-lab/blob/main/day1/student/week1_day1_yourname.ipynb)

Before starting:

1. Open the Colab link.
2. Select **File → Save a copy in Drive**.
3. Keep the filename `week1_day1_yourname.ipynb`, replacing `yourname` with
   your own name.
4. Complete the tasks in order.
5. Open the hints only when needed.

The lab introduces Python, NumPy, Pandas, and a first linear-regression project
using fictional lemonade-sales data. The notebook includes guided tasks and
automatic checks, but it does not contain the final answers.

See [day1/README.md](day1/README.md) for the learning goals and class outline.
