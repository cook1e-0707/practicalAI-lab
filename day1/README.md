# Week 1, Day 1 — Python, Data, and a First ML Model

## Learning goals

By the end of the lab, you should be able to:

- run and modify code cells in Google Colab;
- distinguish numbers, strings, and Booleans;
- use variables, arithmetic, lists, comparisons, `if`, `for`, and a simple
  function;
- read the final line of common Python errors and try a fix;
- explain the difference between a list, a NumPy array, and a Pandas DataFrame;
- load a CSV file and select rows and columns;
- identify features and a prediction target;
- explain training, validation, and test data;
- use `.fit()` to train and `.predict()` to make predictions;
- use MAE to compare simple models.
